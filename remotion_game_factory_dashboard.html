How to use Remotion Game Factory

        From game idea to AI-ready specification and production tracking
      

      
    


    

      1. Define
      2. Configure
      3. Export
      4. Generate
      5. Track
    


    
1. Create a game specification

    

      Start in Game Builder. Give the game a name, clinical domain, therapeutic objective,
      patient population and a short description. The Game ID is generated automatically if you leave it empty.
    


    
2. Describe the gameplay

    

      Explain what the patient does, the session duration, repetition target, difficulty strategy,
      completion rule and feedback behavior. Keep the game mechanics clinically meaningful and simple enough
      for the selected population.
    


    
3. Select the input modality

    

      Choose Touchscreen, Motion Tracking, Camera, Hand Tracking, VR, Head Tracking, Audio, Speech,
      Gyroscope or External Sensor. Extra fields appear automatically according to the selected input.
      Use a fallback input such as Mouse when possible so the game can be tested without the final hardware.
    


    
4. Define therapist controls

    

      Select the parameters the therapist should be able to configure: speed, target size, side,
      movement amplitude, distractors, cognitive load, assistance, cues, time pressure and repetition goal.
      Add custom parameters when the activity needs something specific.
    


    
5. Select metrics and events

    

      Choose the standard Remotion metrics and add game-specific metrics using the format:
      metricId | type | unit | description.
      Example: maxReach | number | normalized | Maximum horizontal reaching distance.
    


    
6. Export the game package

    

      Use Export JSON for the machine-readable source of truth,
      Export DOC for a readable specification,
      and Export AI Prompt to generate the actual game with an AI coding tool.
      You can also copy the prompt directly.
    


    
7. Save versions and track development

    

      Click Save version whenever the specification changes. The History page keeps every saved
      version in this browser. The Registry page shows the latest saved version of each game.
      Update the lifecycle checkboxes as the game progresses through generation, review, testing, hosting,
      Remotion integration and publication.
    


    
8. Import an existing JSON

    

      Click Import JSON and select a Game Factory JSON file. The dashboard will repopulate
      the form so you can edit, version or regenerate the AI prompt.
    


    

      Recommended workflow
      

        Idea → Game Factory specification → Save version → Export AI Prompt → Generate HTML →
        Developer review → Local test → Clinical test → Host → Integrate into Remotion → Publish.
      

    


    

      Important
      

        The JSON should remain the canonical specification. When the game changes, update the Game Factory record
        and save a new version instead of silently modifying the implementation.
